User Defined Functions (UDFs)

Las UDFs permiten crear funciones personalizadas que se ejecutan en los workers de Spark.

from pyspark.sql.functions import udf
from pyspark.sql.types import StringType

@udf(returnType=StringType())
def mayusculas(nombre):
    return nombre.upper()

df.withColumn("nombre_upper", mayusculas("nombre")).show()

User Defined Table Functions (UDTFs)

Las UDTFs retornan multiples filas por cada fila de entrada usando yield.

from pyspark.sql.functions import udtf
from pyspark.sql.types import StructType, StructField, StringType

@udtf(returnType=StructType([StructField("word", StringType())]))
def split_words(text):
    for word in text.split(" "):
        yield (word,)

split_words("hola mundo").show()

import logging

logger = logging.getLogger(__name__)

Monitoreo con psutil

Monitorea recursos del sistema mientras ejecutas operaciones Spark.

import psutil

print(f"CPU: {psutil.cpu_percent()}%")
print(f"RAM: {psutil.virtual_memory().percent}%")
