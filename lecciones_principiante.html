📖 Guia de PySpark Principiante

SparkSession.builder

SparkSession es el punto de entrada para usar PySpark. Se crea con el patron builder.

from pyspark.sql import SparkSession

spark = SparkSession.builder \
    .appName("MiApp") \
    .getOrCreate()

# Ver version
print(spark.version)

Crear un DataFrame

Crea DataFrames desde diccionarios, listas o archivos.

from pyspark.sql import Row

# Desde diccionario
data = [("Alice", 25), ("Bob", 30)]
df = spark.createDataFrame(data, ["name", "age"])

# Desde lista de Row
df = spark.createDataFrame([Row(name="Alice", age=25)])

show() - Ver datos

Muestra las primeras filas del DataFrame en formato tabular.

df.show()

# Con numero de filas
df.show(10)

# Truncado vertical
df.show(truncate=False)

printSchema() - Estructura

Muestra la estructura del DataFrame con tipos de datos.

df.printSchema()

# Salida:
# root
#  |-- name: string (nullable = true)
#  |-- age: long (nullable = true)

select() - Seleccionar columnas

Selecciona y proyecta columnas especificas.

# Seleccionar columna
df.select("name").show()

# Multiples columnas
df.select("name", "age").show()

# Con expresiones
from pyspark.sql.functions import col
df.select(col("name"), col("age") * 2).show()

filter() / where() - Filtrar

Filtra filas que cumplan una condicion.

# Con string
df.filter("age > 25").show()

# Con columna
df.filter(col("age") > 25).show()

# Con where (igual)
df.where(df.age > 25).show()

withColumn() - Agregar columnas

Crea o reemplaza una columna con una transformacion.

from pyspark.sql.functions import lit

# Nueva columna con valor constante
df.withColumn("country", lit("Mexico")).show()

# Transformacion
df.withColumn("age_doble", col("age") * 2).show()

dropna() / fillna() - Datos nulos

Maneja valores nulos en el DataFrame.

# Eliminar filas con nulos
df.dropna().show()

# Eliminar filas donde una columna sea nula
df.dropna(subset=["name"]).show()

# Rellenar nulos
df.fillna({"age": 0, "name": "Unknown"}).show()

orderBy() / sort() - Ordenar

Ordena el DataFrame por una o mas columnas.

# Ascendente
df.orderBy("age").show()

# Descendente
from pyspark.sql.functions import desc
df.orderBy(desc("age")).show()

# Con sort
df.sort("age", ascending=False).show()

Guardado de datos

Exporta DataFrames a diferentes formatos.

# CSV
df.write.mode("overwrite").csv("output/data.csv")

# Parquet
df.write.mode("overwrite").parquet("output/data.parquet")

# JSON
df.write.mode("overwrite").json("output/data.json")
